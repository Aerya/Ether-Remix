# Ether v0.3.20

A fix release for v0.3.19.

- **Marketplace plugins that add a library install again.** Installing Music, Books and audiobooks, or any other plugin that adds a library from **Plugins › Marketplace** failed with "Could not install plugin". Ether compared the package with its marketplace entry and treated the library it adds as an unreviewed permission. The package is pinned by its checksum, so only the permissions the entry declares are compared now.
